# Stage 8 Admin, configuration and export boundary

ZeusTek Site Logs show application diagnostics generated on this device. They do not claim to include hosting security logs. Entries use fixed messages and numeric details; raw upstream errors, record values, contact data, connection secrets, tokens and stack traces are not stored or exported. The viewer supports domain, severity and date filters, CSV/JSON, clear, and bounded 30-day/2,000-entry retention. Existing legacy logs are read only through the safe projection and never included verbatim in downloads.

Site Configuration has separate cards for cloud/device overview, Household, Skill Catalogue, Equipment/training lists, category icons, agency logos, Insights awards, My Maps, Dive numbering, Weather & Conditions, News/inbox, fixture review and other data tools. Each domain save reads the latest settings, validates only its own fields, and preserves other settings and unknown future fields. Weather status reports provider access truthfully; a configured provider is not labelled usable until checked.

Diver Summary PDF, DOCX, TXT, CSV and JSON are rendered from the same explicit owner-selected projection. Equipment is included when selected. Certification numbers and card images require separate opt-in. Private notes, cylinder serials, internal IDs and unselected sections are excluded; CSV formula cells are neutralised. Failed card images retain certification text and report a count, without exposing image or network error details.

The cloud backup endpoint selects canonical record kinds at the database query and projects them through the same allowlist before serialisation. Local encrypted backups likewise exclude unknown or server-only record types, their event/pending metadata and secret-bearing reviews. Older cloud backup files containing the formerly included `gmail-connection-secret` row restore ordinary records while discarding that row. Existing live connection credentials are not overwritten by a restore. A restored account without a connection must reconnect the dedicated Dive News mailbox through OAuth; backup files cannot restore Gmail credentials. Dummy-credential tests cover both routes and ordinary-record restoration. Existing historical private backup evidence remains ignored and must not be copied into the repository.
